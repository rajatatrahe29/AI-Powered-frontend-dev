## ⚡ Free 1-Click Hosting on Vercel

This Next.js application is pre-configured for **zero-config deployment on Vercel** (free Hobby tier).

### Method 1: Deploy via GitHub (Recommended)
1. **Push your code to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Rajat Atrahe AI Portfolio"
   git branch -M main
   git remote add origin https://github.com/rajatatrahe/portfolio.git
   git push -u origin main
   ```
2. Go to **[vercel.com](https://vercel.com/)** and sign in with your GitHub account.
3. Click **"Add New..."** → **"Project"**.
4. Import your `portfolio` repository.
5. Vercel automatically detects Next.js settings. Click **"Deploy"**.
6. Your portfolio is live in under 60 seconds with a free `.vercel.app` URL and automatic HTTPS! Every new push to `main` will automatically trigger a production deployment.

### Method 2: Deploy via Vercel CLI
If you prefer deploying directly from your terminal:
```bash
# In the portfolio directory:
npx vercel
```
Follow the interactive prompts (log in via browser, press Enter to accept defaults). Vercel will build and assign you a free deployment URL immediately.

## 🛠️ Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
